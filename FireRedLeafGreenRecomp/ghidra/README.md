# ghidra/

`import_symbols.py` is a Ghidra Jython script generated by
`tools/import_pokefirered_symbols/`. It applies the FireRed function and
data symbols to the currently-open program (the cart loaded at
`0x08000000`).

Usage in Ghidra: **Window → Script Manager → load `import_symbols.py` →
Run.** Symbols outside the program's address range are skipped.

Regenerate it (alongside the symbol TSVs) with:

```sh
python tools/import_pokefirered_symbols/import_pokefirered_symbols.py
```

Only this `README.md` and the generated `import_symbols.py` are tracked;
the Ghidra project DB (`.gpr` / `.rep`) stays local (see `.gitignore`).

Symbol typing is heuristic — see `../symbols/README.md`.
